# App Creater Tapper

Unfinished Unity 2017.3 reaction game written in UnityScript.

Gesture images (fist bump, handshake, high five) cycle on screen. When a prompt hits, tap the matching button. A wrong tap ends the round. The project also has a main menu, a short tutorial, and a stats screen for high score, favorite gesture, and time spent.

This is an archive of an unfinished project.
